# Original resources

These are manufacturer references transcribed from the printed documents supplied with the IN12_M4 clock. They are external resources; this desktop project is independent of their publisher.

| Resource | Link | Printed source |
| --- | --- | --- |
| Manufacturer website | [diym.vip](https://diym.vip) | English IN12_M4 manual, printed page 1; Chinese leaflet, electronic-manual section |
| Website address on the leaflet | [www.diym.vip](https://www.diym.vip) | Chinese leaflet, contact section (the printed address omits the scheme) |
| Original Guoran Android APK | [guoran.apk](https://diym.vip/upload/guoran.apk) | English IN12_M4 manual, printed page 2, “Android APP download” |

The leaflet also identifies a WeChat mini-program as **XG_Clock** and includes WeChat and Taobao QR codes. No verified web destinations have been extracted for those QR codes, so no guessed links are provided.

These are the historical addresses printed in the supplied material, not a guarantee of current availability or compatibility. The original Android APK may not install on recent Android versions. It is linked for reference and is not bundled with this project's releases.

The manufacturer scans are not included in the public repository because they also contain a device-specific warranty label. The English user guide summarizes the operating instructions; it does not claim to be an official manufacturer translation.
